# VRTrainJourney2026

## 프로젝트 소개

`VRTrainJourney2026`은 Meta Quest 2를 대상으로 제작한 Unity 기반 VR 관광 열차 체험 프로젝트입니다. 사용자는 가상 열차의 2층 전방 전망석에 앉아 세 개의 여행 구간을 순서대로 감상할 수 있습니다.

이 프로젝트는 실제 이동이 어렵거나 장거리 여행이 부담스러운 사용자가 VR 환경 안에서 편안하게 여행 분위기를 경험할 수 있도록 기획되었습니다. 체험은 앉은 자세를 기준으로 구성되며, 전방 창문을 통해 풍경 영상을 감상하고, 한국어 음성 안내와 배경 음악을 함께 들으며 여행 흐름을 따라가도록 설계되었습니다.

## 프로젝트 목표

- 사용자가 안정적인 앉은 자세로 VR 여행을 체험할 수 있도록 구성
- 열차 전방 창문을 중심으로 한 직관적인 시야 흐름 제공
- 세 개의 서로 다른 분위기의 여행 구간을 순차적으로 감상
- 영상, 배경 음악, 한국어 음성 안내, 화면 전환 효과를 결합한 몰입형 Demo 구현
- Meta Quest 2에서 실행 가능한 가벼운 VR 체험으로 완성

## 주요 기술 스택

- Engine: Unity `6000.3.16f1`
- Render Pipeline: Universal Render Pipeline `17.3.0`
- XR Framework: OpenXR `1.16.1`
- Interaction: XR Interaction Toolkit `3.3.2`
- Target Device: Meta Quest 2
- Build Target: Android APK
- Main Scene: `Assets/Scenes/SampleScene.unity`

## 체험 구성

프로젝트는 세 개의 여행 구간으로 구성되어 있습니다.

1. `Golden Village`
   - 따뜻하고 평온한 시골 마을 분위기의 첫 번째 구간입니다.
2. `Fjord View`
   - 넓은 자연 경관과 차분한 풍경을 중심으로 한 두 번째 구간입니다.
3. `Aurora Flower Field`
   - 환상적인 오로라와 꽃밭 이미지를 중심으로 한 마지막 구간입니다.

각 구간은 전방 창문에 표시되는 영상, 배경 음악, 한국어 음성 안내로 구성됩니다. 구간이 전환될 때는 화면이 자연스럽게 어두워졌다가 다음 장면으로 이어지도록 제작했습니다.

## 체험 흐름

1. 사용자가 Meta Quest 2를 착용하고 프로젝트를 실행합니다.
2. 사용자는 가상 열차 내부의 전방 좌석에 앉은 상태로 배치됩니다.
3. 첫 번째 여행 구간인 `Golden Village`가 시작됩니다.
4. 각 구간마다 영상, 배경 음악, 한국어 음성 안내가 함께 재생됩니다.
5. 구간이 끝나면 화면 전환 효과를 거쳐 다음 구간으로 이동합니다.
6. 세 번째 구간인 `Aurora Flower Field`가 끝나면 전체 여행 체험이 마무리됩니다.

## 사용 방법

1. Unity Hub에서 Unity `6000.3.16f1` 버전으로 프로젝트를 엽니다.
2. `Assets/Scenes/SampleScene.unity` 씬을 엽니다.
3. Meta Quest 2를 PC에 연결하고 Android 빌드 대상으로 설정합니다.
4. Unity에서 Android APK를 빌드한 뒤 Meta Quest 2에 설치합니다.
5. Quest 2에서 앱을 실행하고 앉은 자세로 체험을 시작합니다.

## 조작 방법

Meta Quest 2 오른쪽 컨트롤러를 기준으로 조작합니다.

- `A` 버튼: 재생 시작, 일시정지, 다시 재생
- `B` 버튼: 다음 여행 구간으로 이동
- 오른쪽 스틱 누른 상태 유지: 첫 번째 구간부터 다시 시작

기본 체험은 별도의 복잡한 UI 없이 진행되도록 구성되어 있으며, 사용자는 간단한 버튼 조작만으로 전체 여행 흐름을 제어할 수 있습니다.

## 프로젝트 특징

- 앉은 자세 중심의 VR 여행 체험
- 전방 전망석을 활용한 열차 여행 콘셉트
- 세 구간으로 나뉜 순차적 여행 구성
- 영상과 오디오를 분리하여 더 자연스러운 연출 구현
- 한국어 음성 안내를 통한 체험 흐름 전달
- Meta Quest 2에서 실행 가능한 경량 VR Demo
